# Actualización consolidada posterior al enlace del sitio

Esta versión reúne:

- impresión y opción Guardar como PDF para planes y registros;
- eliminación de la tarjeta informativa Publicación en Deportes;
- líderes provisionales del medallero durante la semana;
- cierre del medallero el viernes a las 3:00 p. m.;
- ganadores fijos hasta el lunes a la 1:00 a. m.;
- consejos y tips nuevos en cada visita a un deporte;
- Minutos de hoy y racha calculados con la fecha de Ciudad de México;
- actualización inmediata del dashboard después de registrar una actividad.

## Instalación

1. En Supabase abre SQL Editor y ejecuta completo `supabase/ACTUALIZACION_CONSOLIDADA_POST_LINK.sql`.
2. Sube a GitHub todo el contenido de esta carpeta reemplazando los archivos existentes.
3. Espera que Netlify muestre Published.
4. Abre el sitio y presiona Ctrl + F5.

El SQL puede ejecutarse aunque ya hayas usado alguna de las correcciones separadas: reemplaza las funciones sin duplicarlas.
